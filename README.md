**设置 → Apple 账户 → 订阅 → ChatGPT**

查看目前是否存在有效的 Plus 订阅，以及下一次续费日期。

Android 用户则可以通过 Google Play 的订阅管理页面检查。

这里要注意，Apple、Google Play 和 ChatGPT 网页端属于不同的订阅管理渠道。

假如你在 App Store 购买了 Plus，又直接在 ChatGPT 网页端订阅 Pro，而原来的苹果订阅没有正确取消，就可能产生重复扣费。

取消自动续费通常不会立即结束已经付款的会员周期，因此也不需要为了升级而匆忙重复购买。
